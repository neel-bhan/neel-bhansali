# Neel Bhansali - Living Portfolio System

Personal portfolio for Neel Bhansali, CS + Data Science student at the University of Wisconsin-Madison, Class of 2027.

[neelbhansali.com](https://neelbhansali.com)

## Overview

This site is built as a single-page Living Portfolio System: a futuristic portfolio interface for projects, experience, leadership work, and an in-progress auto-updating GitHub portfolio pipeline.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
